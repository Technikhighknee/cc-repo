This is for me to wget inside of computercraft :)  

## Downloader  
### Install:  
`wget https://raw.githubusercontent.com/Technikhighknee/cc-repo/refs/heads/main/bin/download.lua`  

### Usage:  
`downloader <source> [destination]`  

### Example: 
`downloader turtles/cobble-gen-miner.lua startup.lua`  
saves to `startup.lua`  

`downloader turtles/cobble-gen-miner.lua`  
saves to `cobble-gen-miner.lua`
